# 界面去模板痕迹

审计范围是写作工具里天天要看的几块：章节编辑器、目录和写作侧栏、作品库、登录、模型配置。路由、接口和业务判断没有改。配色仍用 [界面视觉](16-ui-refresh.md) 里的护眼 token，控件内边距仍是纵向 12px、横向 16px。

这是给人写作用的屏幕，不是介绍页。没有大标题横幅，也没有三列图标卡。

## 每块屏幕先回答的问题

- 编辑器：这一章写到哪，它在书里的位置是什么。
- 作品库：要打开哪一部。
- 登录：能不能进去。
- 模型配置：哪一个模型已经能用。

正文列是这件产品自己的东西：衬线、18px、行高 1.7，落在居中的一列里。侧栏用色阶让开，不跟正文抢。编年史是同一条侧栏里的一页，用同一套实底分段条、无静息阴影的卡片，以及不少于 16px 的横向内边距。

## 去掉的痕迹

- 顶栏的磨砂玻璃和半透明底。顶栏是不透明画布，下面一条 1px 线。
- 卡片、列表、健康状态、分段控件选中态上的静息阴影。阴影只留在浮层：导出菜单和确认框。
- 侧栏和卡片不再靠边框叠边框分开。浅色里侧栏是暖灰，正文区是纸色，卡片和行用表面色与抬起一层错开。深色里同一套 token 反过来：侧栏上的块用抬起一层，纸上的块用表面色。
- 目录当前章不再铺强调色。选中是中性的一块填色，字重不变成另一种颜色。
- 顶栏、目录、侧栏、正文格式条的分段控件加宽轨道和间距。按钮自己的 12px / 16px 内边距不动。章节视图的分段条只包住「正文 / 章节大纲」，不拉成整列宽的一条。
- 章节标题不再在悬停时把字从贴边挪到 16px。标题、正文、版本行始终留出横向 16px，焦点环不会切到字上。
- 空状态不再是居中的线框插画。留下实底块、一句话和原来的那个操作（新建作品、新建章节）。
- 焦点环是 2px 实线强调色，不再用半透明光晕。
- 去掉标题上方的小标签（「个人长篇」「作品」「设置」），以及侧栏切换时的上移淡入。

## 留着的

- 浅色暖纸、深色石板、强调蓝、危险色和成功色的 token 数值。
- 主按钮仍用强调色填充，一屏一个主要动作。
- 正文字体、行宽和主题切换（系统 / 浅色 / 深色）。
- `--control-py` 与 `--control-px`。
