# 12 模型配置中心

对照 release 1.0.0 方案里的模型配置中心、数据与安全、接口、统一调用层、模型选择，以及对应测试。实现加在现有 FastAPI、SQLAlchemy、Alembic 和 React 页面上，没有换技术栈，也没有重写作品、正文或大纲。

## 现状与方案

| 项 | 改之前 | 方案要求 | 本次 |
|---|---|---|---|
| 配置页 | 设置页可新增、编辑、删除、测试 OpenAI 兼容或模拟配置 | 列表、表单、测试、默认、状态 | 补服务商、状态、设默认、清除密钥、自定义 Header |
| 服务商预设 | 只有「OpenAI 兼容 / 模拟」 | 数据驱动预设，改过的 Base URL 保留 | `provider_presets.json`，接口返回，页面按数据渲染 |
| 字段 | 名称、地址、模型、加密密钥、参数 JSON、启用 | 另有服务商、Header 密文、默认、测试状态和时间、错误码 | `0012_model_config_center` 接在故事线迁移之后追加列。超时、温度、最大输出仍在 `parameters` |
| 默认模型 | 不传 `model_config_id` 时用最近更新的已启用外部模型 | 单一默认；仅测试成功可设；删除默认须先另选 | 增加 `is_default`。没有默认时仍回退到最近的外部模型，避免已有数据突然不能生成 |
| 测试 | 发 `ping` 且要求非空文本；不记状态 | 最小真实请求，分类错误，成功才可默认 | 保存测试结果。关键字段变化变为「配置已变更，需重新测试」 |
| 错误分类 | 鉴权、超时、限流、不可用、坏响应混在一起 | 密钥、鉴权、地址、模型不存在、限流、网络、超时、响应不兼容 | 上游状态和异常映射到这些类别，响应和日志不含密钥 |
| Header | 无 | 加密存储，响应不回值 | Fernet 密文，只返回 Header 名 |
| 密钥编辑 | 留空保持；不能显式清除 | 留空保持，并提供清除 | `clear_api_key` |
| SSRF | 只校验 http/https | 拒绝回环、内网、云元数据；限制重定向；部署级允许名单 | 保存和调用都检查。不跟随重定向。`MODEL_BASE_URL_ALLOWLIST` |
| 主密钥 | 生产拒绝占位符；开发可先启动，保存时才失败；从不写明文 | 缺失则启动失败，不降级明文 | 任何环境缺少有效 Fernet 密钥都拒绝启动 |
| 调用层 | 续写、分析、冲突、质量各自解密并选最近配置 | 统一层，接受 `model_config_id`，缺省用默认 | `app.ai.gateway` 负责解析和解密。各功能仍用自己的业务规则 |
| 任务记录 | `ai_tasks.model_config_id` 和快照里的 `model_name` | 记录模型标识和配置 ID | 快照补上 `model_config_id`。分析提案、冲突检查、质量检查响应也带回所用配置 |
| 创作入口切换 | 续写面板可选模型 | 各 AI 入口可指定本次模型 | 续写、章节分析、质量检查和冲突检查可以选本次配置 |
| 备份 | 整库已含 `secret_ref` | 备份带密文，恢复后能解密；文档说明主密钥另存 | 清单标明密文依赖 `APP_SECRET_ENCRYPTION_KEY`，密钥本身不进备份 |
| 测试 | 有密钥不回显和适配器单测 | pytest 与 Vitest，mock 上游，不调用收费模型 | `test_model_config_center.py`、预设与设置页测试 |

章节大纲候选已经可以指定 `model_config_id`。不传且不要求模拟时，用已启用的默认模型；还没有默认时，用最近更新的已启用外部模型。预览响应带回所用配置和模型标识，并且不写正式大纲。故事线、卷大纲、编年史和伏笔目前仍是人工编辑，没有单独的生成接口。

## 接口

沿用 `/api/v1/settings/models`。新增预设列表、单条读取、`POST /{id}/test` 和 `PUT /{id}/default`。全部需要登录。

测试状态：`untested` 未测试，`success` 成功，`failed` 失败，`stale` 配置已变更、需重新测试。显示名称、启用和重试次数变化不使测试失效。

## 安全

- 主密钥只来自环境变量。启动时用 Fernet 校验，失败即退出。
- API Key 与自定义 Header 只以密文入库。列表返回 `api_key_configured`、尾号和 Header 名。
- 日志格式化会打码 Bearer 和常见密钥形状；测试断言失败日志不含提交的密钥。
- Base URL 拒绝用户信息、回环、私网、链路本地、云元数据主机名，以及八进制写法的回环地址。允许名单按主机名匹配，由部署环境设置。
