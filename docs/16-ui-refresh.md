# 界面视觉重做

审计对象是 `frontend/src`：作品库、登录门、章节工作台（目录、正文、大纲、生成、设定、质量、创意）、模型配置，以及全站唯一的样式表 `index.css`。路由、接口和业务判断没有改。

## 动手前

整站是一块羊皮纸色（`#ebe4d4` / 深色 `#161310`），只跟 `prefers-color-scheme`，不能手动切换。界面和正文共用衬线，标题特别大。按钮是胶囊形，列表、输入框、侧栏都靠 1px 边框切开。顶栏还写着内部代号。正文编辑区是带框的输入块，没有写作行宽。标签页用实心主按钮，选中和未选中的尺寸感不一样。空状态是虚线框。确认动作走浏览器原生 `window.confirm`，样式跟页面脱节。侧栏不能收起，也没有过渡。

深色只是把羊皮纸改成深棕，不是一套可写作的石板色。浅色大面积偏黄，对比和留白都不像现在的写作工具。

## 参考来源

配色和动效按下面四家的公开做法取，不另起一套色。

| 来源 | 取用的部分 |
|---|---|
| MemoNotepad 的 Obsidian Slate | 深色画布用石板蓝，不用纯黑。画布 `#0F172A`，卡片 `#1E293B`，抬起一层 `#334155` |
| [Tokyo Night](https://github.com/enkia/tokyo-night-vscode-theme)（enkia） | 强调色 `#7AA2F7`。这个蓝比纯蓝柔，用来做主按钮、焦点和选中 |
| Craft、Calliope | 浅色暖纸。画布 `#FCF9F7`，卡片 `#FFFCFA`。正文用石板色 `#1E293B`，不用纯黑字压纯白纸 |
| Linear | 交互节奏。颜色、阴影 160ms `ease-out`；侧栏收起 220ms。悬停只换背景，不跳动。键盘焦点用强调色环 |

## 定稿 token

默认跟随系统，顶栏可以改成浅色、深色或回到系统。选择记在 `localStorage`（`novel-workbench-theme`），首屏脚本先写到 `<html data-theme>`，避免闪一下。

### 深色（主写作）

| 角色 | 值 |
|---|---|
| 画布 | `#0F172A` |
| 表面 / 侧栏 | `#1E293B` |
| 抬起一层 | `#334155` |
| 边框 | `#334155` |
| 主文字 | `#F8FAFC` |
| 次文字 | `#CBD5E1` |
| 弱文字 | `#94A3B8` |
| 强调 | `#7AA2F7` |
| 暖色提示 | `#FBBF24`，只做成功条的细标记和后端正常的小圆点 |
| 危险 | `#F87171` |

`#F8FAFC` 落在表面 `#1E293B` 上大约 13:1，落在画布上大约 17:1。不是纯白字压纯黑底。

主按钮字用 `#0F172A`。`#7AA2F7` 本身偏亮，浅色字压上去对比不够。

### 浅色

| 角色 | 值 |
|---|---|
| 画布 | `#FCF9F7` |
| 表面 | `#FFFCFA` |
| 抬起一层 / 侧栏底 | `#F3EEE9`、`#F6F1EC` |
| 边框 | `#E7E1DA` |
| 主文字 | `#1E293B` |
| 次文字、弱文字 | `#64748B` |
| 强调填充 | `#3B82F6` |
| 强调文字 / 链接 | `#1D4ED8` |
| 危险填充 | `#F87171` |
| 危险文字 | `#BE123C` |

浅色主文字对暖纸大约 13:1。链接不用 `#3B82F6` 直接当小字，那个蓝在暖纸上偏浅；填充按钮仍用 `#3B82F6`，字用 `#0F172A`。危险小字同理：填充保持柔和红 `#F87171`，浅色表面上的文字改成更深的玫瑰，否则读不清。弱文字在浅色里用 `#64748B`，不用深色那档 `#94A3B8`，否则在暖纸上低于正文对比。

差异高亮用低饱和绿和红。暖黄不铺满成功条，只做一条 3px 标记。

## 交互

- 界面字体是系统无衬线。正文字号 18px、行高 1.7，衬线，写作列最大 44rem（704px），落在 680–720px 里。
- 按钮圆角 10px。主按钮实心强调色，次按钮是细边框幽灵按钮，危险是柔和红字或柔和红填充。
- 卡片靠表面色和很轻的阴影分开，列表悬停只提亮背景。
- 目录和侧栏可以收起，宽度过渡 220ms。窄屏改成上下叠放，不把内容夹没。
- 标签切换有 220ms 的淡入。尊重 `prefers-reduced-motion`。
- 空状态是一行说明、一个小标记，加上一个主操作（新建作品 / 新建章节）。
- 滚动条改细，颜色压低。
- 确认框换成页面内的 `<dialog>`：取消、确定，删除类用危险按钮，Esc 和点遮罩等于取消。应用入口挂了对话框宿主。单元测试单独渲染组件时，宿主不在，仍走原来的 `window.confirm`，所以既有「会先询问」的测试不用改判断。

## 前后

| | 之前 | 之后 |
|---|---|---|
| 底色 | 羊皮纸黄 / 深棕，不能手切 | 暖纸 + 石板蓝，系统 / 浅色 / 深色 |
| 强调 | 砖红 `#8C3A2F` | 浅色 `#3B82F6`，深色 `#7AA2F7` |
| 正文 | 带框输入区，衬线用在按钮和标题上 | 居中写作列，界面无衬线，正文衬线 |
| 结构 | 边框叠边框，标签是胶囊主按钮 | 表面分层，分段控件，侧栏可收 |
| 确认 | 浏览器原生对话框 | 与页面同一套 token 的对话框 |
