# 写作交互

目录、生成侧栏和章节头改成写作时常用的那几下，路由和接口没变。候选仍然要作者确认后才写入正文。

目录不再给每一章铺一排按钮。行尾的「⋯」里是上移、下移、复制、分析记忆和删除，删除仍会先确认。卷的改名和删除卷也在这个菜单里。拖动一行会调整顺序；章节可以拖到别的卷，用原来的章节移动和卷排序接口。

生成页以续写、润色、改写、扩写开头。选中一个动作，只留下这一次的要求。模型、字数、必须包含和不要出现收在「更多设置」里，缩写和校对也在那里。将发送的内容可以先看；「存为我的指令」记在这台浏览器里，不另开接口。上下文可选仅本章，或再加上大纲、角色设定。作者单独固定纳入的材料仍然优先。设定、质量、创意和编年史还在原来的侧栏里。

章节标题、状态、同步和字数合成一行。格式按钮在选中正文后出现。专注收起顶栏、目录和右侧栏，Esc 或左侧「退出专注」可以回来。这个选择会记住。
